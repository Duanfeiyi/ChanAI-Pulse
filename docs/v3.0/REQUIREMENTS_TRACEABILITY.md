## 状态含义

- `已冻结`：项目规则已经确认，但不表示所有相关代码已经完成。
- `待实现`：需求明确，等待对应 Step 实现。
- `进行中`：已有分支或 PR 正在实现。
- `已验证`：代码、测试和文档均已通过验收。
- `阻塞`：缺少授权、依赖、数据或必要决定。

## 更新规则

每个 Step 的 PR 必须检查本表：

1. 将受影响需求改成正确状态；
2. 填写或链接具体测试；
3. 不允许仅因为“界面看起来能运行”就标记为 `已验证`；
4. 科学计算相关需求必须同时有固定输入和可复现结果。
