## 1. 目标

完成三个目标：

1. 补齐普通用户从常见 MAT 数据进入标准 v3 HDF5 流水线的安全转换入口；
2. 用清晰、现代的横向填充式进度条替换现有指针/刻度式进度显示；
3. 把 Step 0～13 的输入、标定、优化、预测、生成、可视化、导出和独立 Benchmark
   整理成稳定、诚实、可复现并可发布的 v3.0 基线。

- 不把只有 PDP/DPSD 功率、缺少相位的数据伪装成完整复数 CIR。

## 3. 已冻结的 MAT 转换规则

以下规则已由项目负责人全部选择A并冻结，实施中不再重复询问：

1. **输入版本：** 支持 MAT v7、MAT v7.3、普通复数变量、实部/虚部分离、SAGE 文件夹和旧 WiFo HDF5；
2. **表示方式：** 同时支持 CIR 和 CTF，但必须由高置信度识别或用户明确指定；
3. **未知 MAT：** 普通模式仅采用安全自动识别，高级模式允许显式映射变量与维度；
4. **功率-only：** PDP/DPSD 可以检查和分类，但拒绝转换成完整复数 CIR，也不进入正式预测链路；
5. **可选信息缺失：** 允许转换并降低能力等级，不支持的图显示原因；
6. **用户补充：** 允许填写带宽、频率、采样/时延间隔、位置、单位和维度含义，并写入 Manifest；
7. **输出：** 用户选择目录，创建新 HDF5，永不覆盖源文件；成功后可直接加载；
8. **批量范围：** 第一版支持单个普通 MAT 和已知 SAGE 文件夹批量转换，不对任意混合文件夹盲目批量猜测；
9. **UI：** 在模块一提供正式中英文分步向导，包含普通模式和高级模式；
10. **大文件：** 优先只读元数据，转换尽可能分块读取/写入并显示明显进度；
11. **样本编号：** 缺少样本坐标时可生成 `1:Nsample`，但不得声称为真实时间或位置；
12. **宣传边界：** 表述为“支持已知格式和用户显式映射的 MAT”，不承诺任意 MAT 都能自动识别。

## 4. 已冻结的进度 UI 规则

现有指针/刻度式进度显示在 Step 14 中废弃。统一组件采用横向填充式读条：

```text
正在转换 MAT 数据                         62%
███████████████████░░░░░░░░░░░░
阶段 3/5：分块写入标准 HDF5    已用时 00:18
[取消当前任务]
```

规则如下：

1. 进度区域足够大，不在界面边缘溢出，也不遮挡主页面；
2. 横条随真实进度从左向右填充，右侧显示百分比；
3. 同时显示总阶段、当前子任务、已用时间和可理解的状态；
4. 已知总工作量时显示确定百分比；工作量未知时显示动画读条，不伪造百分比；
5. 运行中用蓝色，完成用绿色，警告用橙色，失败用红色；
6. 支持取消的后台任务必须提供明显的取消按钮；
7. 模块一分析、MAT 转换、模块二 Grid/SA/生成、模块三预测/生成使用同一组件和相同语义；
8. Benchmark 只有在真实可计算总量时显示百分比，否则使用不确定读条；
9. 中文/英文切换后，阶段、错误、取消和完成信息全部同步；
10. 后端必须通过 progress callback 报告真实阶段，UI 不使用定时器制造虚假进度。

### Step 14B：MAT 转换合同与只读检查器

统一定义转换请求和结果：

- 输入文件/文件夹、MAT 版本、数据表示（CIR 或 CTF）；
- 复数变量，或显式实部/虚部变量；
- `Tx/Rx/Nf或Npath/Nt/Nsample` 维度映射；
- 时延、频率、时间、位置和阵列轴；
- 单位、来源、场景和用户补充说明；
- 输出 v3 HDF5、转换 Manifest、警告和拒绝原因。

只读检查器先读取变量名、类型、尺寸、实数/复数属性和 MAT 版本。大文件优先读取元数据，
不能为了识别格式先把全部数组加载到内存。

**产物：** MAT 检查报告、转换合同和可测试的错误码。

### Step 14C：已知格式 Adapter 与通用映射器

- SAGE MAT 文件夹：调用已有 `convert_sage_folder_to_v3_hdf5`；
- 旧 WiFo HDF5：调用已有 `convert_legacy_wifo_hdf5_to_v3`；
- 普通复数 MAT：支持一个复数变量；
- 分离复数 MAT：支持明确选择实部和虚部变量；
- 未知 MAT：高级模式允许用户显式指定维度顺序和物理轴；
- 单例维仍保留，统一输出五维 `[Tx,Rx,Nf或Npath,Nt,Nsample]`；
- 转换过程中绝不覆盖或修改源文件。

只有 PDP/DPSD 功率、模型特征或预测结果而没有复数相位时，明确说明不能恢复完整 CIR；
它们可以被检查和分类，但不得进入正式 CIR 预测链路。

**产物：** 新的通用 MAT→v3 HDF5 转换服务和专用 Adapter 调度器。

### Step 14D：转换预览与正式 UI 向导

在 `ChannelSimulator` 模块一增加“MAT 转换向导”入口，采用分步交互：

1. 选择 MAT 文件或已知格式文件夹；
2. 自动识别格式，显示变量、尺寸和复数属性；
3. 普通模式采用安全推荐；高级模式映射变量、维度、单位和物理轴；
4. 预览标准五维形状、能力类别和预计可画的 1/3/6/9 图；
5. 用户确认输出目录后转换；
6. 转换成功后可直接加载新 HDF5 进入模块一。

中英文必须同步；进度、取消、失败原因和输出位置必须清楚。普通模式不能自动猜测含义不明确的数组。

**产物：** 正式 MAT 转换向导，不是独立临时 Demo。

## 7. 人工验收重点

1. `ChannelSimulator` 能从正式入口启动；
2. 已知 MAT 能自动转换，未知 MAT 可手动映射，功率-only MAT 被诚实拒绝；
3. 源 MAT 不被修改，输出 HDF5 和 Manifest 可追溯；
4. 所有长任务使用横向填充式读条，大小清楚、不出界、不再出现指针式进度；
5. 百分比来自真实进度，未知工作量不显示虚假百分比，取消和终态正确；
6. 转换后四类数据对应正确 1/3/6/9 图；
7. 内插、外推及目标区间映射正确；
8. 自动生成器逐候选尝试，全部失败才报错；
9. 普通模式无需操作模块二，高级模式可查看实际策略和理由；
10. 模块三如实显示 P6/P8 + Persistence，不伪装神经网络；
11. 导出包不含目标 Ground Truth，但独立 Benchmark 能读取原始完整数据公平评价；
12. 中英文主要页面和错误提示无残留；
13. 私有数据和受限第三方核心未进入发布包；
14. 所有结果可由 Manifest 追溯；
15. v3.0 基线 Manifest、Git revision 和 Release Notes 完整。
