# Step 5 统一信道特性引擎科学规则

> 状态：2026-07-29 经项目负责人确认，作为 Step 5 实现基线。

## 1. 目标

Step 5 接收 Step 4 已验证的 v3 `ChannelDataset` 和可选
`ChannelTask`，计算可信、可追溯、可复用的信道特性。

同一引擎以后同时服务：

- 模块一的输入信道特性；
- 模块三由预测参数经 6GPCM 生成的预测 CIR 特性。

它不比较 Ground Truth，不计算预测准确度。

## 2. 总原则

1. 数据能力决定图表，不能为了固定布局制造占位数据。
2. 1、3、6、9 是四类理想信道的标准特性集合，不是强制数量。
3. 时延—样本热力图是附加图，不计入 1、3、6、9。
4. 物理坐标来自文件或可审计推导，不能根据数组长度猜测。
5. 计算与绘图分离；绘图器不重新推导科学指标。
6. 正式任务默认只分析 `known_indices`，避免目标区域泄漏。
7. 所有输出记录单位、聚合、归一化、来源和警告。

## 3. 标准特性集合

| 信道类型 | 理想标准特性 |
|---|---|
| 窄带静态 SISO | 功率 |
| 宽带静态 SISO | PDP、频率自相关、时延扩展经验 CDF |
| 宽带静态 MIMO | 上述三项 + 角度功率谱、空间相关、角度扩展经验 CDF |
| 宽带动态 MIMO | 上述六项 + 多普勒功率谱、时间自相关、多普勒扩展经验 CDF |

某项缺少可信输入时只返回“不支持”和原因，不补图。
四类标准组合的正式界面只开放表中的标准特性和声明为附加的热力图，
不把内部可计算但未纳入该分类的其他 metric 混入下拉框。非四类标准组合
可以开放科学上可用的 metric，但不显示没有依据的 `x/10` 标准数量。

## 4. 功率

内部基础量：

```text
P_linear = |H|²
P_dB = 10 log10(P_linear)
P_normalized_dB = P_dB - max(P_dB)
```

引擎保留线性功率、原始 dB 和归一化 dB。默认图显示归一化 dB。
只有输入明确具有绝对功率标定时，原始 dB 才能解释为绝对功率。

## 5. 维度与聚合

先保留逐 `Tx/Rx/time/sample` 结果，再生成汇总。默认规则：

- PDP：对选定区域内的 Tx、Rx、时间和样本等权平均；
- DS/角度扩展/多普勒扩展：先逐样本计算，再形成经验分布；
- 相关性：先保留复数相关，再默认显示幅度；
- `N_sample` 在形成 CDF 前不能提前平均掉。

每个指标必须报告被平均和被保留的维度。

## 6. 任务区域

有合法任务时默认使用 `known_indices`：

- `sample`/`position`：裁剪第五维；
- `time`：裁剪第四维；
- `frequency`：只对 CTF 第三维裁剪。

完整数据只允许在明确的审阅模式中分析，不能静默进入预测输入。

## 7. PDP 与时延扩展

- CIR 使用 `cir.delay_s`、`cir.coefficient` 和 `cir.path_valid`；
- CTF 只有在频率轴均匀且明确时才通过 IFFT 得到离散 CIR；
- 缺少可信时延坐标时，不输出带物理单位的 PDP/DS；
- RMS 时延扩展使用线性功率加权；
- 无效路径、NaN、Inf 和零总功率必须显式处理。

## 8. 经验 CDF

- `N_sample = 1`：不输出 CDF；
- `N_sample = 2～19`：允许输出，同时给出样本较少警告；
- `N_sample >= 20`：达到第一版推荐数量；
- 使用排序后的经验分布，不用高斯拟合代替真实 CDF；
- 同时报告中位数和 90% 分位数。

## 9. CIR 到 CTF

只有以下信息足够时才派生频率响应：

- 明确的频率采样数量；
- 中心频率；
- 子载波间隔或等价频率网格；
- 可信逐径时延。

派生必须记录频率网格和公式。缺少信息时频率自相关不可用。

## 10. 相关函数

频率和时间自相关保存归一化复数值：

```text
R(k) = E[x(n+k) conj(x(n))] / E[|x(n)|²]
```

默认图显示 `|R(k)|`，同时保留相位和复数结果。

## 11. 多普勒

要求：

- `Nt > 1`；
- 存在严格递增的 `time_s` 或明确 `snapshot_interval_s`；
- 时间间隔在容差内均匀。

第一版使用 Hann 窗和 FFT，输出横轴单位 Hz，并记录采样率、窗函数和
FFT 长度。不均匀时间轴不自动重采样。

## 12. 角度

- 按本项目冻结的维度规则，角度图首先要求 `Tx > 1` 或 `Rx > 1`；
- CIR 的 `aoa_rad` 和 `aod_rad` 分开处理；
- 路径功率作为角度功率谱权重；
- 只有明确阵列类型、阵元间距和载频时，才允许从复数阵列响应计算波束空间角谱；
- SISO 文件即使附带生成器的逐径角度，也不在模块界面开放角度图；
- 没有路径角度或阵列几何时不猜角度谱；
- 角度扩展按样本计算后形成经验 CDF。

## 13. 空间相关

返回归一化复数 Tx/Rx 相关矩阵，默认图显示幅度热力图。

- 至少需要两个可用于相关估计的信道观测；
- 有阵列几何：可以附带物理阵元位置；
- 只有天线维度：只能标注为天线索引相关性；
- 不把天线索引直接解释成物理距离。

## 14. 时延—样本热力图

仅在以下条件同时满足时开放：

- 宽带或多径数据；
- `N_sample > 1`；
- `sample_semantics` 明确为有序；
- 具有可信时延。

横轴优先使用路线累计距离，否则使用样本编号；纵轴为时延，颜色为归一化功率。
