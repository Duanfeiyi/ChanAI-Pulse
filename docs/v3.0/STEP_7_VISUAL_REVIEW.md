# Step 7 Demo 与人工审阅说明

> 审阅目标是确认“搜索流程和结果解释正确”，不是评价最终 UI 美观程度。

## 1. 打开 Demo

```matlab
addpath("examples");
step7_grid_search_demo
```

默认选择 6GPCM-lite，并搜索：

```text
DS_mu：3个候选
KF_mu：3个候选
num_clusters：3个候选
总计：3 × 3 × 3 = 27个候选
```

## 2. 界面各区域是什么意思

- 顶部配置区：选择生成后端，输入三个参数的候选列表；
- 候选数：运行前显示笛卡尔积大小和 500 上限；
- 搜索分数图：灰色点线是每个候选分数，绿色线是运行到当时找到的最低分；
- PDP 对比：目标已知区域与最佳候选的功率—时延分布；
- DS 对比：两者 RMS 时延扩展分布；
- Top 候选表：总分以及 PDP、DS 两个分数组成；
- 后台事件：验证、目标分析、每次生成和完成阶段；
- 结论区：最佳参数、分数组成、WARNING/FAIL 和科学边界。

## 3. 推荐人工操作

### A. 默认 Lite 搜索

1. 保持默认 27 个候选；
2. 点击“开始 Grid Search”；
3. 等待完成。

应看到：

- 候选数确实是 27；
- 进度逐步增加，不是瞬间伪造排名；
- Top 表最多 5 行；
- 最佳参数包含 `DS_mu`、`KF_mu`、`num_clusters`；
- 分数越低排名越前；
- 两张对比图使用相同横坐标或分位概率；
- Lite 的工程限制仍以 WARNING 说明。

### B. 精确检查笛卡尔积

把候选改为：

```text
DS_mu：-8.05,-7.925
KF_mu：-0.39
num_clusters：8,12,16
```

应显示 `2×1×3=6` 个候选，并最终完成 6 个，而不是随机选择或重复。

### C. 非法和超限输入

- 候选列表输入非数字，应明确失败；
- 同一列表放两个相同数值，应在运行前拒绝；
- 让候选乘积超过 500，应拒绝且不开始生成。

失败时不得保留上一次成功结果的曲线冒充本次结果。

### D. 取消

开始较大的搜索后点击“取消”。

应看到 `CANCELLED`，后续候选不再运行。已经找到的临时低分不能显示成正式完整答案。

### E. Full 6GPCM

选择 Full 并填写外置根目录。Demo 会自动缩小为两个 `DS_mu` 候选，避免人工审阅耗时过长。

应看到真实 Full 后端身份、完整运行结果和核心未修改记录。路径错误时必须
`FAIL`，不能偷偷退回 Lite。

## 4. 怎样判断图是否“合格”

合格不等于两条线必须完全重合。应检查：

- 如果真实参数就在候选网格里，确定性 Demo 的最佳两条线应重合或非常接近；
- 如果故意移除真实参数，最佳分数可以大于 0，这是合理结果；
- PDP 横轴是时延，不是样本编号；
- DS 图比较的是整组样本的分位分布；
- 这些图用于解释参数拟合，不是预测准确率图。
