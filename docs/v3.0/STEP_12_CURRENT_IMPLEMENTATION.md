## 唯一启动入口

在项目根目录的 MATLAB 命令窗口执行：

```matlab
cd("<ChanAI-Pulse 项目根目录>")
ChannelSimulator
```

不需要调用旧的 `ChannelSimulatorApp`，也不需要运行任何 Demo 脚本。

## 当前已经接通的正式路径

1. 模块一读取 v3 HDF5 信道文件，建立内插/外推任务，验证数据并按真实维度显示可用特性图；不能画的图会显示原因。
2. 单击“开始预测”后，模块二在后台仅用 **known 区域**做 Grid/SA 标定；窄带单抽头没有可辨识 PDP 时明确使用能力默认标定，不伪造 DS 拟合。普通用户不必在模块二操作，高级用户可选择 `auto/grid/sa` 与 Lite/Full 后端。
3. 模块三使用当前冻结注册表批准的 **Persistence** 基线，将模块二的已知区标定参数扩展到目标区，再经 6GPCM 生成预测 CIR、CTF、特性图与 Manifest。
4. 目标区 Ground Truth 不会进入这条产品预测路径；正式 UI 不显示 RMSE、NRMSE、准确度曲线或真值对比图。
5. 普通模式按能力自动选择：SISO 优先 Lite，MIMO 自动使用可配置 Full 公共 API Adapter。外部 Full 核心保持只读，Tx/Rx/Nt 不会被缩减。高级用户手选不可用后端时明确失败，不静默替换。
6. 四套标准输入已经真实完成“导入→标定→预测→CIR/CTF→特性图→导出回读”，模块三标准图数分别为 `1/3/6/9`。

## 本轮 UI 修正

- 文件选择或导出对话框关闭后，正式 App 主动恢复正常窗口并回到前台；
- 模块一增加 `Tx/Rx/Nf/Nt/Npath/Nsample` 维度卡、数据类型和“标准+附加”图数；
- 增加绿色 known、橙色 target 的任务区间色条，以及原始轴到 MATLAB 索引的对照；
- 1/3/6/9 标准图与热力图分离，全部概览和每个分类页签均显示图数；
- 模块二使用真实优化事件驱动进度条，并展示标定参数表；
- 模块三增加 DS/KF 参数轨迹，Persistence 的水平延长被如实显示；
- 新增可配置 Full 6GPCM 公共 API 包装层，已验证 `Tx=2、Rx=4、Nt=16`，核心目录前后 SHA-256 一致；
- 窄带输出转换为一个未分辨复抽头，使1图输入不会被生成器错误升级为宽带3图；
- 独立目标之间仍禁止路线热力图，但每个目标内部连续 Nt 的多普勒、时间自相关和多普勒扩展图合法保留；
- 修正过大的开始按钮、固定像素状态区和中间图表区域偏小的问题。

## 重要的 v3.0 边界

- Step 12 Extra/Step 14 已补齐正式界面的中文/英文切换；科学标识和 Manifest 字段保持稳定英文，展示层标题、按钮、状态和图表说明随语言切换。
