# ChanAI Pulse v3.0 版本命名

## 1. 正式版本号

v3.0 使用语义化版本形式：

```text
v主版本.次版本.修订版本
```

本轮目标正式版本为：

```text
v3.0.0
```

v3.0 代表产品任务、数据契约和三模块职责发生明显升级，不表示此前每个中间版本都必须发布。

## 2. 开发阶段

| 版本 | 对应 Steps | 主要成果 |
|---|---:|---|
| `v3.0.0-alpha.1` | 0–2 | 需求、数据契约、四类测试数据 |
| `v3.0.0-alpha.2` | 3–5 | 完整 6GPCM 最小调用、模块一、特性引擎 |
| `v3.0.0-alpha.3` | 6–7 | Generator Adapter、真正 Grid Search |
| `v3.0.0-beta.1` | 8–10 | 随机搜索、SA、Predictor Adapter |
| `v3.0.0-beta.2` | 11 | 预测参数到 6GPCM CIR 端到端链路 |
| `v3.0.0-rc.1` | 12–13 | 三模块 UI、外部 Benchmark |
| `v3.0.0` | 14 | 回归、文档、授权检查和正式验收 |

## 3. Tag 规则

- 普通 Step 完成不强制打 Tag；
- 达到上表中的完整里程碑后才创建预发布 Tag；
- Tag 必须指向已经合并到 `main` 的提交；
- 正式 Tag 由项目负责人确认后创建；
- 不在未通过测试的个人分支上创建正式 Tag。

## 4. 文档版本

需求和数据契约可以使用独立文档版本，例如：

```text
v3.0-requirements.1
v3.0-data-contract.1
```

文档版本变化不自动等于软件发布版本变化。
