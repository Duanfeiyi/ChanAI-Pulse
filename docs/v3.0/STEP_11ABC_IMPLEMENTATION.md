# Step 11A–11C 实施记录（v3.0）

本文件记录 Step 11ABC 已冻结的工程规则与本轮实现边界。训练数据、模型权重、检查点和外部 6GPCM 源码均不进入 Git；本仓库只保存可复现的接口、代码、测试和说明。

## 已实施的 11A：泛用预训练数据

- 参数顺序固定为 `DS_mu, KF_mu, DS_sigma, KF_sigma, r_DS, LNS_ksi, num_clusters, num_rays`；P2/P4/P6/P8 是这个顺序的前缀，绝不交换列。
- 40 条独立路线，每条 120 个连续参数样本；按路线切分为 30 个训练组、5 个验证组、5 个测试组。
- 对每个任务/参数包形成 8 个 HDF5 文件。每条路线可形成 `120 - 16 - 4 + 1 = 101` 个窗口，训练分区为 `30 × 101 = 3030` 个窗口。
- 场景基线来自完整 6GPCM 的公开 `simulation_parameters` / `setScenario` API；平滑路线扰动是确定性的、带种子的工程训练路线，不被表述为真实测量标签。
- 连续轨迹 CIR 封装为 `generate_step11abc_full_route`。实测验证数据只允许作为本地外部测试，默认不放入 Git，也不参与泛用预训练。

## 已实施的 11B：多模型、多种子、保守选择

- 分别训练 GRU、LSTM、TCN；每个候选使用至少 3 个随机种子。
- 同时比较 Persistence 和 Linear 两个简单基线。
- 神经网络只有同时满足下列规则才可成为普通用户自动模型：
  1. 平均验证 NRMSE 至少比最佳基线低 10%；
  2. 至少胜过 60% 的独立验证路线；
  3. 任一验证路线误差不超过该路线基线误差的 2 倍。
- 否则自动回退到最佳简单基线。高级用户将来仍可在兼容的 GRU/LSTM/TCN 之间手动选择；界面接入属于 Step 12。

## 已实施的 11C：软件外端到端验证

- 测试对中，真实参数和预测/补全参数采用同一个随机种子调用未修改的 Full 6GPCM。
- 记录参数 NRMSE、标准化 PDP NRMSE 与 RMS 时延误差；Full 6GPCM 核心哈希在每次调用前后复核。
- P2/P4/P6/P8 依次比较。当一个较小参数包的端到端 PDP 评分在最佳分数 5% 以内时，普通用户优先使用参数更少的包；高级用户仍保留兼容手动选择。
- 准确度表、误差图、隐藏测试真值仅属于软件外测试材料；产品模块三只展示预测 CIR 与由数据维度决定的信道特性图。
