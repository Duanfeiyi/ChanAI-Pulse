## 3. 完整版 6GPCM 特别规则

项目负责人在 2026-07-28 确认：

- 可以为了 ChanAI Pulse v3.0 进行封装和增加调用接口；
- 6GPCM 内部核心实现不修改；
- 经项目负责人确认的相关资源可以进入现有公开仓库。

正式纳入前仍应完成：

1. 记录提供方、取得日期和版本；
2. 保留原始 `LICENSE`、`NOTICE`、版权头和引用说明；
3. 建立“核心文件清单 + 哈希”，用于证明核心没有被改动；
4. 把 ChanAI Pulse 新增代码放在独立 Adapter/Wrapper 目录；
5. PR 中单独列出第三方文件和项目新增文件；
6. 如果上游许可证禁止某种发布方式，立即停止对应发布并以许可证为准。
