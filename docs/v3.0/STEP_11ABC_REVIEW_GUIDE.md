# Step 11ABC 人工审阅指南

## 先看什么

1. 打开 D 盘数据目录中的 `step11abc_corpus_manifest.json`：确认 40 条路线、8 个 HDF5 文件、3030 个训练窗口和 P2/P4/P6/P8 定义。
2. 查看每个 `*_step11abc_registry.json`：确认每组有 3 个随机种子，且自动选择理由不是“偷偷看了测试真值”。
3. 查看 `formal-end-to-end/step11abc_end_to_end_summary.csv`：PDP NRMSE 越小，说明用该参数包重新生成的信道功率-时延特性越接近隐藏真值。
4. 查看 `step11abc_bundle_selection.json`：确认普通用户自动包遵守“最佳分数 5% 内优先较少参数”的规则。

## 如何理解本轮结果

本轮路线是平滑、短跨度的合成参数路线。Persistence（“把最近已知状态延续下去”）很强，神经网络没有达到预先约定的 10% 优势，因此注册表安全地选择了 Persistence。这不是模型系统失效，而是避免在证据不足时夸大 AI 效果。

端到端比较仍可能偏向 P8：P8 包含更多待生成参数，因此未预测参数由“校准值→场景值→默认值”补全时造成的信息损失更小。该结论只对本次数据版本、场景和验收规则有效；加入真实路线或更多动态/空间参数后必须重新运行 Step 11ABC。

## 平台边界

这些误差图不应放进正式平台界面。模块一和模块三只显示由输入维度允许的 PDP、相关函数、角度/多普勒特性等信道图；误差验证留在本文件对应的外部测试流程。
