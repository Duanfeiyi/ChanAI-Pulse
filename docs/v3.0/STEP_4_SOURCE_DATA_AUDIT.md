# Step 4 整理版信道数据审计

> 审计对象：团队本地整理版中的 `05_数据`，源数据只读。
>
> 审计日期：2026-07-29。
>
> 本文只记录相对目录和科学判断，不登记个人计算机绝对路径，不把真实测量文件提交到公共仓库。

## 1. 结论

整理版中没有可以不经处理直接作为 v3 正式输入的文件，但存在三类有用资产：

1. SAGE 实测参数结果可以通过专用文件夹转换器形成 v3 CIR；
2. 旧 WiFo HDF5 可以通过专用 Adapter 形成 v3 路径域 CIR；
3. DPSD、训练输入输出和预测结果已经丢失复数相位，只能用于旧模型复现或外部 Benchmark，不能恢复为完整 CIR。

正式 Step 4 仍只接收单个 v3 标准 `.h5`。旧数据转换发生在正式入口之前，源文件不被覆盖。

## 3. SAGE 实测结果

### 3.1 MovingR1

- 文件数：100；
- 文件时间范围：`0-1s` 至 `99-100s`；
- 顶层变量：`sage`，尺寸 `1×2 cell`；
- 每个 record 均含 `alpha/doa/delay/cir_e/cir/likelihood`；
- `cir` 固定为 `1×16×683` 复数数组；
- SAGE 参数路径数量随文件变化，约 52～100。

潜在 v3 CIR：

```text
Tx=1, Rx=16, Npath/tap=683, Nt=1, N_sample=100
```

阻塞信息：

- `sage{1}` 和 `sage{2}` 的物理含义尚未确认；
- 时延单位、实际带宽、载频、阵列排列尚未确认；
- 因此不自动合并两个 record，也不自动映射 `alpha/doa`。

### 3.2 横向道路1～5

每条道路 337 个 MAT，共 1685 个。所有文件都能读取，均含：

```text
alpha, doa, dod, delay, cir_e, cir, mse
```

所有 `cir` 固定为 `1×16×683` 复数数组。SAGE 参数表第二维随文件变化，但不影响固定 CIR tap grid。

| 道路 | 文件数 | delay 数值范围 |
| --- | ---: | ---: |
| 1 | 337 | 139.5～156 |
| 2 | 337 | 141～156.5 |
| 3 | 337 | 142～176 |
| 4 | 337 | 142～186 |
| 5 | 337 | 144～214.5 |

`delay` 单位没有写入文件，不能仅根据数值猜测为 ns。

每条道路可以转换为：

```text
Tx=1, Rx=16, Npath/tap=683, Nt=1, N_sample=337
```

首版转换使用固定 `cir` tap grid；时延网格必须由调用者明确提供 `bandwidth_hz` 或 `delay_bin_spacing_s`。`alpha/doa/dod` 在路径、单位和角度约定确认前不进行猜测映射。

## 4. DPSD 和模型数据

### 4.1 DPSD

- 文件数：2565；
- 变量统一为 `dpsd`；
- 尺寸统一为 `200×1`；
- 全部为实数功率；
- 数值范围约 `2.29e-12`～`7.61e-8`。

DPSD 已丢失复数相位，不能唯一恢复 CIR。Step 4 将其识别为功率特征并返回 FAIL，而不是把第一个数值数组误当成信道。

### 4.2 GRU 输入输出

典型结构：

```text
input_train  : 100×200×10
output_train : 100×200
input_test   : 500×200×10
output_test  : 500×200
predictions  : 500×200
ground_truth : 500×200
```

它们属于基于 DPSD/dBm 的模型特征与结果，留给 Step 13 外部 Benchmark。

### 4.3 “全频段”归档

THz、光无线和 mmWave 子目录中保存的是实数训练/测试数组、预测结果和统计图，没有发现原始复数 6GPCM CIR。文件夹名不能作为数据域证据。

## 5. WiFo 资产

### 5.1 `X_test.mat`

```text
X_val : 1000×24×4×128 complex double
```

WiFo 加载代码把它当作 `[sample, time, antenna, frequency]`。它可能转换成：

```text
Tx=1, Rx=4, Nf=128, Nt=24, N_sample=1000
```

但天线归属、频率轴、时间间隔和样本语义尚未写入文件，因此暂不作为 Step 4 的首个正式 Converter。

### 5.2 19 个 `3D_CSI_*.h5`

全部使用相同结构：

```text
/csi/real : 16×4×8×1000
/csi/imag : 16×4×8×1000
/delay    : 1×8
/gain     : 1×8
/doppler  : 1×8
```

根属性记录 3.5 GHz、20 MHz、1024 子载波、16 Tx、4 Rx 和场景说明。但生成代码表明第三维实际是 8 条路径，`n_subcarriers=1024` 并不对应 `/csi` 第三维。

Adapter 必须要求调用者明确第四维是：

- `sample`：输出 `16×4×8×1×1000`；
- `time`：输出 `16×4×8×1000×1`，并要求明确时间轴或采样间隔。

这些文件由独立随机信道程序生成，没有真正调用 QuaDRiGa，应标记为 synthetic。

## 6. 真实文件技术验证

### 横向道路1

在不改动源文件的前提下，全量读取 337 个 SAGE MAT，使用明确标记为技术假设的 200 MHz tap spacing，临时转换、导入并删除输出：

```text
PASS
Tx=1, Rx=16, Npath=683, Nt=1, N_sample=337
```

该结果证明结构转换和 Step 4 接口可运行，不代表 200 MHz 已被确认为测量真值。

### WiFo `3D_CSI_01.h5`

```text
原始旧 HDF5：FAIL（符合预期）
转换后 v3 CIR：PASS
Tx=16, Rx=4, Npath=8, Nt=1, N_sample=1000
```
