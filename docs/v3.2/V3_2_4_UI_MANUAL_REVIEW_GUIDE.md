- **自动化/无头环境**：编程方式改变下拉值不会自动触发回调（MATLAB uifigure 行为）；交互式点击正常。测试通过显式调用回调模拟点击。
- **模块二对频率轴**：跳过参数优化（确定性恢复不依赖标定；洞状已知区无法构建 PDP 拟合目标），以占位标定通过流程闸门并如实标注"频率轴确定性恢复：不依赖标定"。
- **缺失子载波模式下拉**：当前为文档性 UI（记录意图）；实际已知/目标切分由任务区间决定（80/20 或手动）。模式与切分的一致性校验属 v3.2-4b。
