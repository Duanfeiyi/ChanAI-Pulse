# v3.1-7：真实 P8、任意长度预测与正式产品接入

## 1. 状态与边界

本工作包把 v3.1-5 的 ModelRegistry v2、官方 checkpoint 和 v3.1-6 的生成/Benchmark 边界接入正式 `ChannelSimulatorV3App`。产品版本为 `ChanAI Pulse v3.1.0`；PR #75 已由项目负责人手动合并，Tag `v3.1.0` 和 GitHub Release 仍由项目负责人手动执行。

v3.1 正式生成仍限样本/位置轴。Time/Frequency 完整端到端预测属于 v3.2。Full 6GPCM 核心未修改。

## 2. 用户任务合同

用户任务不再受固定“16 个已知点→4 个目标点”限制：

- 外推：已知索引必须来自上传文件、不能和目标重叠，目标点数可以是任意正数；
- 内插：每个目标缺口必须位于已知范围内部且左右都有已知点，缺口长度可以任意；
- 所有合法已知点均进入预测与本地回测，不截成最后 16 点；趋势模型对靠近目标边界的点赋予更高权重；
- 只有索引/数据合同错误、必要模型上下文不足、运行时/checkpoint 缺失、NaN/Inf 或生成器失败等硬错误才拒绝；
- 回测较差或连续性超出参考值只产生 `WARNING`，仍按高级用户的手选模型生成，且不静默换模型。

## 3. 真实、无泄漏的数据链

1. 只读取任务已知区 CIR/CTF，目标区信道样本不进入提取、选模、适配或预测；
2. 按原始顺序提取局部 P8：
   - `DS_mu`：RMS 时延扩展的 `log10(s)` 中位数；
   - `KF_mu`：主径与其余散射功率之比（dB）；
   - `num_clusters`：相对最强径不低于 -20 dB 的显著径/抽头数代理；
3. 可辨识字段按数据能力动态确定：宽带公开样例可观测 `DS_mu`、`KF_mu`、`num_clusters`；窄带单径数据无法得到局部时延扩展，因此连 `DS_mu` 也冻结。其余不能从局部信道可靠辨识的字段保留模块二标定值；
4. 在上传数据的已知区构造与用户目标长度相同的近期 holdout；历史不足时退为 1 步回测并明确记录，绝不读取真实目标区；
5. 预测参数经过 Registry 合法范围投影、整数计数投影和连续性诊断后交给 6GPCM Adapter；
6. 成功后生成 CIR/CTF，并把全部选择、回测、警告、投影和 provenance 写入 Manifest。

CTF 输入只在均匀频率网格上通过 IFFT 得到时延抽头；不满足该硬条件时明确报错。

## 4. 模型与自动 Hybrid

任意长度原生候选包括：

- Persistence；
- 全历史加权 Linear / Quadratic Trend；
- Holt Damped Trend；
- Harmonic/Fourier（加权频率搜索，可跟随周期/近正弦趋势）；
- Adaptive AR（在已知区选择阶数）；
- Kalman。

普通模式不是为整个 P8 只选一个模型，而是分别对 `DS_mu`、`KF_mu`、`num_clusters` 比较已知区逐参数 NRMSE。不同参数的最佳模型不同时，界面显示 `Hybrid`，图标题显示该参数真正使用的模型。五个不可局部辨识字段显示为 `frozen_known_anchor`。

高级模式可统一手选上述模型及 GRU、LSTM、TCN、DLinear、NLinear。手选结果即使弱于本地最佳基线也继续执行并显示警告；系统不会偷偷改成 Persistence/Kalman。

为同时满足“手选模型要运行”和“橙线不能明显离谱”，产品层增加透明的极端偏差稳定器：某个可观测参数在已知区的误差超过该参数最佳本地基线 4 倍时，不拒绝任务，而是保留至少 10% 的手选模型输出，其余与该参数最佳基线融合。界面标为 `model+local_guard(weight)`，Manifest 记录触发比例、手选模型权重和基线模型；这个过程仍不读取目标真值，因此不是事后偷看答案，也不是静默替换。

## 5. 旧神经 checkpoint 的兼容方式

仓库内 10 个官方神经 checkpoint 的原生训练合同仍是 `[N,16,8] -> [N,4,8]`，且训练目标是生成器 P8 真值，不等同于当前从 CIR 直接观测的三个局部代理。因此：

- 它们保留为 `legacy 16→4` 实验模型，不伪装成任意长度原生模型；
- GRU/LSTM/TCN 的编码器在运行时可接收变长序列，因此第一轮会消费该方向的全部已知点；其输出头仍固定 4 点，超过 4 点时按时间顺序滚动并把已生成点加入下一轮上下文；
- DLinear/NLinear 的线性层输入宽度固定为 16，只能使用靠近目标边界的 16 点；全部历史仍参与本地回测，但不会伪称其固定线性层使用了全部点；
- 内插分别从左向右、从右向左滚动，再按到左右边界的距离加权融合；
- 每次运行在 Manifest 记录具体的 full-history recurrent 或 fixed-16 rolling 合同、调用次数及长预测误差累积警告；
- 神经模型在每个必需方向仍至少需要 16 个已知点，这是 checkpoint 的硬兼容条件，不是用户任务的全局限制；该条件不满足时，可改用自动模式或任意长度原生趋势模型；
- 当前固定语料不足以诚实训练“任意历史/任意输出”的新官方神经 checkpoint，因此本次不制造未经 Benchmark 准入的新权重。后续必须先建立与真实 CIR 局部观测语义一致的变长训练语料，再发布新版本权重。

## 6. 任意长度内插

每个连续目标缺口独立处理：

1. 使用缺口左侧的全部已知点做正向预测；
2. 使用缺口右侧的全部已知点反向预测；
3. 越靠左的目标越信任正向结果，越靠右越信任反向结果；
4. 多个不连续缺口分别预测，再按原目标索引合并；
5. 目标真值始终不可见。

## 7. UI 与可审计结果

- 蓝线显示全部已知区真实局部 P8 观测；橙线显示任意长度目标预测；
- 标题按参数显示真实模型，例如 `DS_mu · HARMONIC`、`KF_mu · AR`；
- 摘要显示 `Hybrid`、逐参数映射、回测窗口数、本地最佳基线和连续性状态；
- 警告不会伪装成失败：CIR 可生成/导出，顶部和状态区显示 `WARNING`；
- 页面只称“已知区回测”，不把它冒充未知目标区准确率；
- Manifest 保存全部已知上下文、目标索引、逐参数模型、各候选分数、回测长度退化、滚动调用、连续性、范围投影和未读取目标真值标志。

## 8. 当前程序化证据

公开 `wideband_static_siso_cir.h5`，已知 1～26、外推 27～32：

- 得到 26 个有序已知 P8 观测和 5 个与 6 点 horizon 匹配的本地回测样本；
- 自动模式选择 `Hybrid`：`DS_mu=harmonic`、`KF_mu=ar`、`num_clusters=persistence`；
- 已知区选模 NRMSE 约 `0.0111`；
- 预测完成后才读取目标区做独立验收，三个可观测参数 holdout NRMSE 约 `0.01174`，不参与选模；
- 连续性比值约 `3.193`，略高于参考阈值 3.0，所以生成结果并显示 WARNING；
- 手选 GRU 可完成 6 点目标，通过两次 4 点原生调用滚动得到所需前 6 点，并记录误差累积风险；
- 该 GRU 的原始公开 holdout NRMSE 约 `1.53`；透明 local guard 在不读取目标真值的情况下把最终公开 holdout 降至约 `0.055`，并保留/登记 GRU 权重，避免再次出现明显离谱的橙线；
- 8 点内插缺口已验证使用左右共 24 个已知点并完成双向融合；
- 人工构造的 60 点周期序列上，Harmonic 的 12 点外推 RMSE 小于 0.25，10 点双向内插 RMSE 小于 0.05。

这些是公开功能回归证据，不构成跨场景泛化保证。正式准确度仍由独立 `ChannelBenchmark` 给出。
