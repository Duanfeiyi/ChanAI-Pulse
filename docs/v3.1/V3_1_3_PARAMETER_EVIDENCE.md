# v3.1-3：参数敏感度、消融与参数包冻结

> 状态：已实现并完成正式本地证据研究，等待项目负责人审阅和手动合并 PR。

## 目标

本阶段不训练 GRU/LSTM/TCN，也不改变 v3.0 正式产品 Registry。它回答一个更基础的问题：P2/P4/P6/P8 中哪些参数确实影响 Full 6GPCM 生成结果，以及后续 v3.1 训练应使用哪个固定参数包。

## 方法

- 使用 v3.1-2 的 `120 × 120` 公开合成参数语料；每个任务/参数包的 Validation 与 Test 分区各有 `1818` 个窗口，切分继续按完整路线组隔离；
- 对 P2/P4/P6/P8 运行无训练的 Persistence 诊断。该指标只描述各包内参数的预测难度，不能跨不同参数维数直接排名，因此不单独决定冻结结论；
- 使用内置 Full 6GPCM **公共 API**，三种代表性公开 profile（sub-6 GHz UMa LoS、cmWave UMa NLoS、mmWave UMi LoS），并实际应用 `0.5/3/8 m/s` 与 `1×1/2×2/2×4` Tx/Rx 配置；
- 每个 profile 使用三个固定随机种子，对 P8 的每一个参数单独进行一次边界跨度 `10%` 的合法扰动；总计 `3 × 3 × 8 = 72` 组对照，加上对应基准生成；
- 记录 CTF 相对 NRMSE、PDP 相对 NRMSE、RMS 时延绝对变化、空间相关变化和相邻快照时间相干变化。公共 API 标准输出没有可审计的逐径角度字段，因此本阶段不虚构角度结论；角度扩展仍属于后续有相应数据支持的工作。

所有 CSV、MAT、Experiment Manifest 和状态记录均在 Git 外资产目录。Full 6GPCM 核心保持只读。

P6 只覆盖约 `73.7%` 的累计综合敏感度，低于已冻结的外推门槛 `85%`。因此，本阶段不能因为 v3.0 历史产品默认使用 P6 就把 P6 继续称为证据支持的 v3.1 训练包。

## 冻结决定

| 任务 | v3.1-3 冻结训练包 | 依据 |
|---|---|---|
| 内插 | P8 | P8 是唯一达到 95% 敏感度覆盖的候选。|
| 外推 | P8 | P6 未达到 85% 覆盖门槛；P8 达到 100%。|

这是一项面向 v3.1-4 训练和 v3.1-5 Registry 的证据冻结，不会回溯修改 v3.0.0 已发布产品中“外推 P6 / 内插 P8 + Persistence”的基线。若未来有独立、覆盖更广场景的证据，可以通过新的版本化 Manifest 再次审议，但不得静默改变顺序、单位、范围或选择分区。

## 运行方法

在仓库根目录运行：

```matlab
addpath(genpath(pwd))
report = run_v31_3_local_evidence();
```

默认输出在仓库同级 `ChanAI-Pulse-v3.1-assets/experiments/`。同一实验 ID 不会被覆盖；若需要重跑，必须使用新的实验 ID，并保留旧记录的状态和 Manifest。
